## 🌟 Overview

**AstroPulse EIMO** is an autonomous, Earth-independent medical decision support and physiological monitoring software suite engineered for long-duration deep-space exploration (Artemis, Lunar Gateway, and Mars Transit).

During communication latency intervals (up to 22 minutes each way during Mars missions), terrestrial telemedicine is unavailable. AstroPulse EIMO empowers astronaut crews and autonomous vehicle systems with real-time health intelligence, predictive deterioration forecasting, and automated clinical triage.

---

## 🛰️ Core Features

- **Bayesian N-of-1 Physiological Digital Twin**: Continuously updates an astronaut's baseline using continuous biometric telemetry (ECG, SpO2, HRV, Core Temp, SANS/ICP markers).
- **5-Hazard Space Environmental Coupling**: Integrates live deep-space environmental stressors:
  1. Space Radiation (GCRs & SPEs)
  2. Microgravity & Fluid Redistribution
  3. Extreme Isolation & Circadian Disruption
  4. Hostile / Closed Spacecraft Environment
  5. Earth-Distance Comms Latency (Autonomous Edge Decision Loop)
- **Interactive Body-Zone Biotelemetry Map**: Visual SVG/Canvas anatomical mapping with clickable body regions, telemetry overlays, and immediate triage protocols.
- **Autonomous Clinical Countermeasures**: Evidence-based medical intervention trees and step-by-step guidance under zero-telemedicine constraints.
